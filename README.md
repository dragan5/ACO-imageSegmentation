# Image Segmentation using Ant Colony Optimization

Studentski projekat iz predmeta **Računarska inteligencija** na Matematičkom fakultetu Univerziteta u Beogradu.

Cilj projekta je primena algoritma **Ant Colony Optimization (ACO)** na problem segmentacije slika.

## Tehnologije

* Python
* Jupyter Notebook
* NumPy
* OpenCV
* Matplotlib

## Opis projekta

U projektu je implementiran pristup segmentaciji slika zasnovan na algoritmu **Ant Colony Optimization**.

Implementacija omogućava eksperimentisanje sa različitim parametrima algoritma i analizu dobijenih rezultata segmentacije.

Pored same implementacije, projekat sadrži i postupak evaluacije rezultata i poređenje dobijenih segmentacija.

## Sadržaj repozitorijuma

* `aco.ipynb` — implementacija ACO algoritma i segmentacije
* `evaluation.ipynb` — evaluacija rezultata
* `simple_bgr_segmentation.ipynb` — jednostavan pristup segmentaciji zasnovan na BGR kanalima
* `dataset/` — skup slika korišćen za eksperimente
* `aco_results/` — rezultati ACO segmentacije
* `simple_bgr_results/` — rezultati jednostavne BGR segmentacije
* `dokumentacija.pdf` — dokumentacija projekta
* `prezentacija.pptx` — prezentacija projekta

## Rezultati

Rezultati segmentacije i evaluacije nalaze se u odgovarajućim direktorijumima i Jupyter Notebook fajlovima.

Projekat omogućava poređenje ACO pristupa sa jednostavnijim pristupom segmentaciji zasnovanom na BGR kanalima.
